# SMART_TASK_MANAGEMENT_SYSTEM

A Smart Task Management System built using Flask, PostgreSQL, HTML, CSS, Pandas, NumPy, and Flask-SocketIO.

## Features

### Authentication
- User Registration
- User Login
- Logout Functionality

### Task Management
- Add Task
- Update Task
- Delete Task
- View All Tasks

### Task Details
Each task contains:
- Title
- Description
- Priority
- Status
- Created Date

### Analytics Dashboard
Using Pandas & NumPy:
- Total Tasks
- Completed Tasks
- Pending Tasks
- Completion Percentage

### Real-Time Notifications
Implemented using Flask-SocketIO WebSockets.

### Frontend
- Responsive UI
- Clean Dashboard
- Task Cards
- Analytics Summary


# Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- Flask-SocketIO
- PostgreSQL
- HTML
- CSS
- Pandas
- NumPy

# How to run:

In terminal: python app.py
Open browser: http://127.0.0.1:5000
